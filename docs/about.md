# About presentation: playback and capture

[Open the presentation](https://textgoeshere.github.io/nisar-hackathon/about.html).
The implementation is `site/about.html`, `site/about.css`, `site/js/about.js`, and the pure
`site/js/about-timeline.mjs` clock. It reuses the existing three.js viewer and slip shaders;
there is no new rendering framework or change to the event viewer's defaults.

## Approved cut

Exactly 30 seconds, silent: question 0–4; NISAR method 4–6.5; our contribution 6.5–9;
terrain/radar reveal 9–13; schoolyard ground account 13–18; twelve-event grid 18–20;
survey/GPS slip finding 20–23; sideways-radar future work 23–26; equal Explore/Create CTAs 26–30.
The final frame holds; playback does not automatically loop. See [the storyboard](video-storyboard.md).

The main proof is NISAR line-of-sight colour on terrain, **not LOS rendered as uplift**. The 20–26 s
animation is explicitly a **survey + GPS model**, exaggerated by the existing model's derived factor
(currently ×1,300); it is not sideways motion measured by NISAR. Its white arrow uses the actual GPS
step, independently of the model prediction. Height stays terrain-only in both shots. Motion is an
illustration, not a recording of the earthquake. Only the 9–10 s reveal changes the camera within a shot.

The photo is the original 1021 × 767 GSJ PNG, not a higher-resolution original or an enlarged pixelated
news preview. Cropping/reframing is CSS-only. Full provenance/terms: [photo notes](../site/about/README.md).
The story pin is school-level, not a surveyed crack coordinate. The grid uses committed radar-layer
stills (motion, coherence or backscatter change as appropriate), not twelve live WebGL renderers.

## Viewing and recording

- Default is paused, with Play/Pause, Replay, Restart, a scrubber and Fullscreen.
- Keyboard: Space play/pause, ←/→ seek one second, R restart, F fullscreen. Form controls retain their
  native keys. Backgrounding the tab pauses playback; it does not silently skip the presentation.
- The normal page includes a readable transcript, scientific limits and credits. It works as a document
  without JavaScript; playing the film requires WebGL and access to the pinned three.js CDN.
- All photos, grid thumbnails, metadata, map layers and the slip model load before Play is enabled.
  Load failures show an error/reload path; they do not start a half-loaded presentation.
- [Clean capture](https://textgoeshere.github.io/nisar-hackathon/about.html?capture=1) letterboxes the 16:9
  stage and hides page furniture. Move the pointer to reveal controls. Space starts with controls hidden.
- Use a **1920 × 1080 viewport**, wait for Ready, then record 30 seconds. The composition and WebGL canvas
  are 1920 × 1080; the responsive player scales the same composition. The page has **no audio**.
- `?t=20` opens a paused deterministic frame. `?autoplay=1` starts only once ready, unless `t` is also
  supplied. Parameters combine, e.g. `about.html?capture=1&t=24.8`.
- `window.about.ready`, `about.state()`, `about.seek(seconds)`, `about.play()` and `about.pause()` are
  the narrow capture/test API. Seeking pauses and does not depend on the order of previous seeks.
- A 30 fps export has 900 frames, at times `i / 30`, `i = 0…899`. No MP4 is generated by this page.
  Screen recording/export and final encoding remain separate production steps.

## Public guide and credits

CREATE points to [create.html](https://textgoeshere.github.io/nisar-hackathon/create.html), a static copy
of [the canonical operator guide](create-event.md), **not a new creation app**. Reading it needs no sign-in;
actually using the pipeline still needs source access, credentials, technical setup and human review.
The owner controls repository visibility. A fresh end-to-end new-event build remains unproven.

[credits.html](https://textgoeshere.github.io/nisar-hackathon/credits.html) is generated from canonical
[CREDITS.md](../CREDITS.md). Both pages are static, script-free and contain no credentials. Rebuild after
editing either source with Marked 18.0.11 installed, or pass a path to its ES module:

    node scripts/render-public-docs.mjs [path/to/marked.esm.js]
    node scripts/render-public-docs.mjs [path/to/marked.esm.js] --check

Do not hand-edit the generated HTML. The renderer checks link rewriting, HTML safety, headings,
code fences and scrollable tables. Unmapped repository-file links resolve against their canonical
GitHub paths and may require repository access until the owner publishes the source.

## Verification

    node --test tests/about-timeline.test.mjs
    node --check site/js/about.js
    PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m pytest -q -p no:cacheprovider
    .venv/bin/python -m pipeline.credits --check

The 10 timeline tests cover all 900 frames, cut boundaries, the six-second slip beat, final hold,
monotonic movement, reversible seeking, zero LOS-as-height, scientific source separation and caption
budget. The existing 19 Python tests cover pipeline/credits and slip contracts.

Browser release checks: full uninterrupted playback, arbitrary seeks, replay/pause, 1080p composition,
portrait/landscape phone-sized readability, no console/network errors, actual Explore/Create destinations,
public credits and the failure path. Browser checks are recorded after inspecting the published page.
